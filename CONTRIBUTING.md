# Contributing to Road to ML

Thank you for using Road to ML. This curriculum is **maintainer-curated**. The canonical reading experience is the [Nabid In Motion Study Hub](https://nabidinmotion.com/).

## Public contributions

**At the moment we do not accept any public contributions.**

That includes:

- Pull requests
- Patches or suggested diffs
- Community edits to lessons, code, or docs
- Guest chapters or co-authored modules

All changes to `main` are made by the maintainer only. This keeps the syllabus consistent, avoids supply-chain risk on the live Study Hub, and lets updates ship on a single timeline.

If you open a pull request, it will be closed with a link to this file. You do not need to delete your fork.

## What you can do

### Report a problem (optional)

You may open a [GitHub Issue](https://github.com/NabidAlam/road-to-machine-learning/issues) only to **report** something broken. That is not a contribution request, and there is no promise of a public reply timeline.

Useful reports:

- Broken or outdated links
- Factual errors in a lesson
- Typos that change meaning

Please include the **file path or module name**, what you expected, and what you saw.

### Learn and fork

- Read and star the repo
- Fork for your own study notes (MIT License)
- Cite the repository if you reuse material in courses or posts

Forks do not receive automatic updates from this repo unless you sync while following upstream changes yourself. A personal fork is not a contribution channel.

## Maintainer-only updates

Updates flow:

1. Markdown edits in this repository (maintainer)
2. Sync into the Study Hub
3. Publish at [nabidinmotion.com](https://nabidinmotion.com/)

## Style reference (for maintainers)

When editing lessons, follow [WRITING-STYLE.md](WRITING-STYLE.md) for tone, numbering (Module vs Stage), and punctuation.

## Questions

Use the Study Hub contact path linked from [nabidinmotion.com](https://nabidinmotion.com/), or open an issue with the **question** label if you only need clarification about the curriculum.

Thank you for learning with Road to ML.
