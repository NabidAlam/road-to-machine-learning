# Recommended Books for Machine Learning

Educational reading list. Prefer free PDFs or author sites when listed. Buying a print copy is optional and never required for this curriculum.

## Beginner-Friendly Books

### 1. **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow**
   - **Author**: Aurélien Géron
   - **Level**: Beginner to Intermediate
   - **Why**: Practical, code-heavy approach with real-world examples
   - **Link**: [O'Reilly](https://www.oreilly.com/library/view/hands-on-machine-learning/9781492032632/)

### 2. **Machine Learning with PyTorch and Scikit-Learn**
   - **Authors**: Sebastian Raschka, Yuxi (Hayden) Liu, Vahid Mirjalili
   - **Level**: Beginner to Intermediate
   - **Why**: Clear theory-plus-code path. Updated successor to the older *Python Machine Learning* Packt title
   - **Link**: [Packt](https://www.packtpub.com/en-us/product/machine-learning-with-pytorch-and-scikit-learn-9781801819312)

### 3. **An Introduction to Statistical Learning (with Applications in Python)**
   - **Authors**: James, Witten, Hastie, Tibshirani, Taylor
   - **Level**: Beginner
   - **Why**: Accessible statistical learning. Labs in Python (ISLP). Free PDF available
   - **Link**: [Free PDF / site](https://www.statlearning.com/)

## Intermediate Books

### 4. **The Elements of Statistical Learning (ESL)**
   - **Authors**: Hastie, Tibshirani, Friedman
   - **Level**: Intermediate to Advanced
   - **Why**: Comprehensive mathematical treatment of ML algorithms
   - **Link**: [Free PDF](https://web.stanford.edu/~hastie/ElemStatLearn/)

### 5. **Pattern Recognition and Machine Learning**
   - **Author**: Christopher Bishop
   - **Level**: Intermediate to Advanced
   - **Why**: Strong mathematical foundation with a Bayesian perspective
   - **Link**: [Free PDF (author / Microsoft Research mirror)](https://www.microsoft.com/en-us/research/uploads/prod/2006/01/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf)

## Deep Learning Books

### 6. **Deep Learning**
   - **Authors**: Ian Goodfellow, Yoshua Bengio, Aaron Courville
   - **Level**: Advanced
   - **Why**: Comprehensive deep learning textbook
   - **Link**: [Free online](https://www.deeplearningbook.org/)

### 7. **Neural Networks and Deep Learning**
   - **Author**: Michael Nielsen
   - **Level**: Beginner to Intermediate
   - **Why**: Free online book with interactive examples
   - **Link**: [Free online](http://neuralnetworksanddeeplearning.com/)

## Specialized Topics

### 8. **Natural Language Processing with Python** (NLTK Book)
   - **Authors**: Steven Bird, Ewan Klein, Edward Loper
   - **Level**: Beginner to Intermediate
   - **Why**: Hands-on NLP introduction with NLTK
   - **Link**: [Free online](https://www.nltk.org/book/)

### 9. **Speech and Language Processing**
   - **Authors**: Daniel Jurafsky, James H. Martin
   - **Level**: Intermediate to Advanced
   - **Why**: Standard NLP and speech reference. Prefer the free draft (3rd edition in progress)
   - **Link**: [Free draft](https://web.stanford.edu/~jurafsky/slp3/)

### 10. **Interpretable Machine Learning**
   - **Author**: Christoph Molnar
   - **Level**: Intermediate
   - **Why**: Practical guide to explaining black-box models (SHAP, LIME, and more)
   - **Link**: [Free online](https://christophm.github.io/interpretable-ml-book/)

### 11. **Reinforcement Learning: An Introduction** (2nd ed.)
   - **Authors**: Richard S. Sutton, Andrew G. Barto
   - **Level**: Intermediate to Advanced
   - **Why**: Classic RL foundations text
   - **Link**: [Free draft / book site](http://incompleteideas.net/book/the-book-2nd.html)

### 12. **Deep Learning for Computer Vision**
   - **Author**: Rajalingappaa Shanmugamani
   - **Level**: Intermediate
   - **Why**: Practical CV with deep learning
   - **Link**: [Packt](https://www.packtpub.com/product/deep-learning-for-computer-vision/9781788295628)

## MLOps and Production

### 13. **Designing Machine Learning Systems**
   - **Author**: Chip Huyen
   - **Level**: Intermediate
   - **Why**: End-to-end production ML systems thinking
   - **Link**: [O'Reilly](https://www.oreilly.com/library/view/designing-machine-learning/9781098107956/)

### 14. **Building Machine Learning Powered Applications**
   - **Author**: Emmanuel Ameisen
   - **Level**: Intermediate
   - **Why**: Idea-to-product path for ML applications
   - **Link**: [O'Reilly](https://www.oreilly.com/library/view/building-machine-learning/9781492045106/)

### 15. **Machine Learning Engineering**
   - **Author**: Andriy Burkov
   - **Level**: Intermediate
   - **Why**: Practical ML engineering habits
   - **Link**: [Free PDF](http://www.mlebook.com/)

## Mathematics for ML

### 16. **Mathematics for Machine Learning**
   - **Authors**: Deisenroth, Faisal, Ong
   - **Level**: Beginner to Intermediate
   - **Why**: Linear algebra, calculus, and probability for ML
   - **Link**: [Free PDF](https://mml-book.github.io/)

### 17. **Linear Algebra Done Right**
   - **Author**: Sheldon Axler
   - **Level**: Intermediate
   - **Why**: Clear linear algebra reference
   - **Link**: [Free online](https://linear.axler.net/)

## Interview Prep (optional)

### 18. **Cracking the Coding Interview** (6th ed.)
   - **Author**: Gayle Laakmann McDowell
   - **Level**: Intermediate
   - **Why**: Classic coding-interview practice. Optional. Not a substitute for building projects
   - **Note**: Pair with in-repo [Interview Prep](interview_prep.md)

## Reading Strategy

1. **Start with**: Hands-On Machine Learning or Machine Learning with PyTorch and Scikit-Learn
2. **Then read**: An Introduction to Statistical Learning (Python) for theory
3. **For Deep Learning**: Neural Networks and Deep Learning (free online), then Goodfellow et al. if you want depth
4. **For Production**: Designing Machine Learning Systems and Building Machine Learning Powered Applications
5. **For Advanced Theory**: The Elements of Statistical Learning

---

*Many titles have free PDFs or HTML editions. Support authors by buying a print or ebook copy if you find the work valuable. This curriculum does not require purchases.*
